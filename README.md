## 🎭 Overview & Story
**NINETY** is a first-person 3D psychological horror puzzle game. The player wakes up chained to an iron bed in a sealed room with a 90-second countdown on the wall. 

The player must search the room, solve environmental clues, and escape before time expires.

### 🧠 The Core Twist
Every rule, clue, and threat was written by the protagonist's own hand. Failure doesn't mean Game Over—getting captured alters your memory integrity and modifies the environment.

---

## 🎮 Gameplay Features
* **90-Second Rule:** A diegetic digital timer on the wall forces high-pressure decision-making.
* **Memory Integrity System:** Getting caught erases/alters clues and player awareness.
* **Environmental Puzzles:** Decipher codes using in-game props (Radio recordings, Tally marks, Notes).
* **Multiple Endings:** 4 unique endings (Good, Altered, True, and Fade Endings) based on capture count and discovered Memory Fragments.
